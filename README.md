# paper-roadbook：3D 纸雕路书

把你自己的一趟旅行，做成一个可以旋转的 3D 纸雕地图网页。

地图像桌上的纸模型：几座低多边形的山，一片湖，一条会动的路线，路边有毡房、小桥、树和动物。点开每个站点，看你自己拍的照片和视频，还有你写的住宿、吃饭、花费。做好的网页可以发给朋友，也可以放在自己的主页上。

你不用会写代码。你对自己的 AI 编程助手说话，助手按这个 Skill 里的流程一步步做。

给没接触过的人解释两个词。「AI 编程助手」是一类能在你电脑上读文件、运行命令、帮你写代码的 AI 软件，Claude Code 和 Codex 都是。「Skill」是一份写给助手看的操作说明，里面有流程、脚本和模板，装上以后助手就知道怎么做路书。

用之前，你需要先装好一个这样的助手。请按该助手官方网站的说明安装，装好并能正常对话以后，再回来看下面的步骤。

## 需要什么

- 一个能操作你电脑的 AI 编程助手，例如 Claude Code 或 Codex。
- 电脑上装了 Node 20.19 或更高（或 22.12 以上）、Python 3.9 或更高、ffmpeg（助手会检查，缺什么会告诉你怎么装）。
- 你的行程：几天、每天去哪几站，加上你想放进去的照片和视频。
- 不需要任何付费 API、账号或 3D 软件。

## 三步开始

1. **装上这个 Skill。** 四种装法见 [INSTALL.md](INSTALL.md)。不想装 Skill 的话，直接复制 [PROMPT.md](PROMPT.md) 里的提示词也行。小红书帖子用的短版提示词见 [PROMPT_XHS.md](PROMPT_XHS.md)。
2. **对助手说：** 「帮我把这趟旅行做成 3D 纸雕路书。」
3. **回答助手的问题，**确认它整理出的行程和地图方位，最后看预览，说哪里要改。

## 助手会做什么

1. 问你每天的站点、住宿、花费，以及照片放在哪个文件夹。缺的信息它会问你，不会替你编。
2. 把整理好的行程列给你逐项确认。
3. 用公开的地形数据算出各站点之间的相对方位，生成一张「地理骨架卡」，请你确认。
4. 按骨架卡摆出微缩地形：山放在哪一侧，湖和河在哪，路线怎么走。摆完会自己检查画面空不空；哪里偏空，它会问你那里真实有什么，你说了才会摆上去，不会替你编。
5. 处理你的照片和视频：缩小体积，并**清除里面的 GPS 位置和拍摄设备信息**。
6. 生成网页，在本地打开让你看，按你的意见改。
7. 你想分享的时候，告诉你怎么放到自己的静态网站托管上。发布前一定先问你。

## 三条原则

- **方位真实，距离压缩，比例不按真实。** 这是微缩景观，用来配照片和攻略，不能拿来导航。网页上会一直显示这句说明。
- **零付费依赖。** 只用免费的开源工具和公开数据。
- **不编造。** 页面里的内容只来自你和公开地理数据。你没写的点评、价格，页面里就是空的。

## 目录

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 给助手的执行流程 |
| `template/` | 网页引擎（Vite + Three.js） |
| `scripts/` | 地理扫描、照片视频处理、数据校验、新建工程 |
| `references/` | 字段说明、构图指南、自造组件方法、常见问题 |
| `examples/demo-trip/` | 一个完整的示例 |
| `assets/glb/` | 9 个可选的 3D 模型 |

### 可选：用 3D 模型替换代码画的摆件

默认的摆件都是代码画的纸雕，不需要任何模型文件。想换成 `assets/glb/` 里的模型时：把要用的文件复制到你工程的 `public/glb/`（建工程时加 `--with-glb` 可以一次复制全部），再在 `scene.json` 对应摆件里写 `"opts": {"glb": "glb/horse.glb"}`。路径是相对 `public/` 的，不要写 `assets/glb/...`，也不要在前面加斜杠。

## 隐私

照片里常带拍摄地点。这个 Skill 会让助手用 `process_media.py` 处理所有照片和视频，输出文件里没有 GPS。你的原始文件不会被改动，也不会被上传到任何地方。页面上放出来的名字、头像、照片，发布到公网之后任何人都看得到，请自己决定放什么。

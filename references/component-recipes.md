# 自己造一个纸雕组件

资产包里没有你要的东西（一头牦牛、一座清真寺、一艘渡轮）时，按这份方法现做一个。全程只写代码，不需要图片、3D 软件或付费平台。

做出来的组件要像**桌上的纸模型**：由几片有厚度的纸叠成，颜色少而平，边缘有一圈深色描线。不追求写实。

## 第 1 步：先判断它属于哪一类

| 类别 | 例子 | 用哪种手法 |
|---|---|---|
| 圆的、对称的 | 毡房、灯塔、水塔、佛塔、树干、罐子 | **旋转体**：画半边轮廓，绕中轴转一圈 |
| 方的、搭出来的 | 房子、桥、城门、车、船、栏杆 | **搭积木**：盒子、圆柱、棱锥拼装 |
| 有机的、活的 | 动物、人、树冠、云 | **剪影叠片**：画侧面轮廓，挤出厚度，多层叠起来 |

一个组件可以混用。例如骑手 = 剪影叠片的马 + 旋转体的帽子。

## 第 2 步：写之前先列清单

动手前用文字回答这 5 个问题，写在文件顶部的注释里：

1. **最小识别特征是什么？** 缩到 60 像素高时，靠哪 2–3 个特征认出它？（骆驼：双峰、长脖子。灯塔：红白条纹、顶上的灯室。）只把这几个特征做足，其他从简。
2. **分成几层纸？** 列出每一层：身体、近侧腿、远侧腿、鬃毛、鞍毯……
3. **用哪几种颜色？** 最多 5 种，从主题色板里取（见第 5 步）。
4. **哪里会动？** 选 1–2 处：腿、脖子、尾巴、炊烟、车轮、旗子。
5. **尺寸**：整体放进一个约 1×1×1 的盒子里，底面在 `y=0`，正面朝 `+x`。

## 第 3 步：三种手法怎么写

所有工具函数都从 `paperkit.js` 引入。

### 手法一：旋转体

```js
import { T, lathe, C } from '../paperkit.js';
// 轮廓点是 [半径, 高度]，从底到顶
const roof = lathe(group, [[0.53,0.32],[0.45,0.40],[0.33,0.49],[0.20,0.56],[0,0.61]], theme.cream, { segments: 48 });
```

要点：轮廓点 5–8 个就够；分段数 32–64 才圆；屋檐、腰线这类细节用单独一圈细环叠上去，不要挤进同一条轮廓。

### 手法二：搭积木

```js
import { box, cyl, cone, rod } from '../paperkit.js';
box(group, [宽, 高, 深], [x, y, z], color);
rod(group, [x1,y1,z1], [x2,y2,z2], 半径, color);   // 两点之间的细杆：拉索、栏杆、旗杆
```

要点：重复的东西（栏杆、窗户、拉索）用循环生成；细杆半径不小于 0.006，否则缩小后看不见；细杆不要加描边。

### 手法三：剪影叠片（动物和人用这个）

```js
import { cut, paintCut, ribbon, leg } from '../paperkit.js';
// 1. 侧面轮廓：一圈 [x, y] 点，顺时针或逆时针都行，15–25 个点
const body = [[-0.46,0.60],[-0.30,0.635], /* … */ [-0.50,0.50]];
// 2. 挤出成有厚度的纸片
cut(group, body, 0.15, coat, { bevel: 0.028 });
// 3. 要在表面画细节（眼睛、花纹、毛流）用 paintCut，回调里是普通的 canvas 2D 绘图
paintCut(group, body, 0.15, coat, (ctx, P, S) => { /* P(x,y) 把模型坐标转成画布坐标，S(d) 转长度 */ });
// 4. 沿一条中心线生成带状轮廓：脖子、鬃毛、尾巴、围巾
cut(group, ribbon([[0.14,0.64],[0.35,0.88],[0.50,0.96]], 0.10, 0.06), 0.18, mane);
```

**这是最容易做坏的一类，必须遵守下面 4 条：**

1. **不要只用一片。** 单片从正面看是一块木板。至少 3 层，沿 z 方向错开：
   - 躯干一片（最厚，约为身长的 1/5）
   - 胸、臀各加一片稍小的副层，叠在躯干两侧，让正面看有宽度
   - 近侧腿和远侧腿各一片，z 方向分开，远侧颜色深一号
2. **轮廓先写关键点再加密。** 先定 8 个关键点（鼻尖、耳根、肩、背最低点、臀、尾根、后腹、前胸），确认比例对了，再在每段之间补点。
3. **检查比例的参照**：四足动物腿长约等于躯干高度；头长约为身长的 1/3；脖子比你以为的要长。
4. **附属物比身体略宽**：鞍毯、鬃毛的厚度要比躯干大 0.03–0.05，否则被埋在里面，从侧面看不到。

## 第 4 步：细节从哪里来

精致感来自这四样，不来自面数：

- **倒角**：`cut` 的 `bevel` 参数，身体类 0.02–0.03，小零件 0.005–0.01。
- **描边**：`finish(group)` 会自动给所有零件加一圈深色外轮廓。每个组件最后都要调用它。
- **程序贴图**：花纹、条纹、砖缝、羽毛用 canvas 画出来贴上去（`paintCut` 或 `CanvasTexture`）。一个重复的小图案比一张大图好。
- **季节层**：`theme.season === 'winter'` 时在顶部加一层奶白色的雪（屋顶、驼峰、树梢）。雪层单独一片，不要改底下的颜色。

## 第 5 步：颜色规则

- 只用 `theme` 里的颜色。需要新颜色时，从已有颜色调深或调浅，不要引入一个全新的色相。
- 一个组件最多 5 种颜色，其中强调色（红）面积不超过 15%。
- 相邻的两层要有明度差，否则缩小后会糊成一块。人骑在马上、货放在车上时，两者不能是同一个色系。

可用的主题色键名（组件里写 `theme.键名`，不要写死色值）。两套预设的色值如下，`summer-meadow` 没列出的键和 `winter-blush` 相同：

| 键名 | 用途参考 | winter-blush | summer-meadow |
|---|---|---|---|
| `pink` | 底色、纸面 | `#FAEDED` | `#E7F1DF` |
| `cream` | 浅米色，主体纸色 | `#F6E9E3` | `#F1EBD9` |
| `beige` | 米褐，次级纸色 | `#E9D9C3` | 同左 |
| `coffee` | 咖啡棕，最深的描边和文字 | `#603C2C` | 同左 |
| `brown` | 中棕 | `#8B5E4A` | 同左 |
| `red` | 强调色，面积不超过 15% | `#B91C24` | 同左 |

| `light` | 暖黄，灯光、窗 | `#FFC977` | 同左 |
| `ivory` | 象牙白 | `#FFF8F0` | 同左 |

## 第 6 步：组件文件模板

放在你工程里的 `src/components/custom/` 下，引擎会自动注册。

```js
// yak.js — 牦牛
// 识别特征：弯角、肩部隆起、垂到地面的长毛
// 分层：躯干 / 肩副层 / 近侧腿×2 / 远侧腿×2 / 长毛裙边 / 角×2
// 颜色：深棕、黑棕、角的米色
// 动画：低头吃草（头部绕肩转动）
import { T, cut, paintCut, ribbon, leg, finish } from '../paperkit.js';

export default {
  type: 'yak',
  make(opts = {}, theme) {
    const group = new T.Group();
    // … 建模 …
    return finish(group, (t, dt) => { /* 动画 */ });
  },
};
```

然后在 `scene.json` 里写 `{ "type": "yak", "x": 10, "z": 5, "s": 5 }` 就能摆上地图。

## 第 7 步：做完必须自己看一眼

写完不算完成。运行组件预览页（`npm run dev` 后打开 `/gallery.html?type=yak`；夏季工程加 `&season=summer`，即 `/gallery.html?type=yak&season=summer`），它会从三个角度显示组件。逐项检查：

- [ ] **斜俯视**：缩到 60 像素高还认得出是什么吗？
- [ ] **正侧面**：轮廓比例对吗？腿、脖子有没有太短？
- [ ] **正前方**：是不是一块窄板？是的话回到第 3 步加副层。
- [ ] 有没有零件被埋在别的零件里看不见？
- [ ] 相邻颜色有没有糊在一起？
- [ ] 动画有没有让零件穿模或脱离身体？

有一项不过就改，改完再看。看不了画面的环境下，至少把每一层的包围盒打印出来，确认厚度方向不小于宽度的 1/3。
